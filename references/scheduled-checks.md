# 每 20 分钟唤醒检查

## 设置

1. 使用当前环境的自动任务工具，优先当前对话的 heartbeat。检查现有自动任务，按 Skill 与同一 job_id 匹配；已有任务则更新，不能创建重复检查。遵循工具的完整字段更新规则。
2. 创建从现在起每 20 分钟检查一次的计划。当前 Codex 工具使用 `kind: heartbeat`、`destination: thread`，状态为 ACTIVE；不要建立独立对话或用常驻 Python 进程替代。具体参数以当次工具说明为准，不向用户显示原始调度表达式。
3. 计划提示中保存原 job_id、Skill 所在位置、费用授权状态、检查/交付/停止条件。不保存 API Key、科研原文或附件内容。保留工具返回的自动任务 ID。
4. 工具确认创建或更新成功后，结束当前回复。没有可用调度工具或创建失败时明确说明尚未设置自动检查，保留原 job_id；不能声称会自行醒来。

## 每轮执行

- 调用一次 `status JOB_ID`，不调用 submit、run 或持续等待命令。
- 已下载的有效 PNG 直接交付；尚在处理、结果 409 或短暂网络错误则安静结束，等待下一轮 20 分钟检查。
- 完成且费用已授权时运行 `fetch JOB_ID`，验证 PNG 并展示图片及可打开的文件链接，重新查询并显示余额，然后暂停此自动任务。
- 费用仍待确认时不得领取或取消。若用户明确要求继续定时查看，可只查状态；完成后通知一次并暂停，等待费用确认。调度请求、更新 Skill 或发布指令均不代表额外费用授权。
- 失败、取消、过期、用户停止或无法自行解决的鉴权/权限问题：通知真实原因，保留原任务并暂停此自动任务。不得重提收费任务。
- 交付后若暂停失败，明确说明并重试暂停；下一次唤醒先处理停止，不能重复交付或重新提交。

## 计划提示模板

> 使用 <Skill 路径> 检查原任务 <job_id>，每次只查询一次，不重新提交，不启动持续等待。费用授权状态：<实际状态>。未完成或短暂网络错误时保持安静并结束本轮，等待下一次计划检查。完成且费用已授权时领取并验证 PNG，在当前对话展示图片、文件链接及实时余额，再暂停本自动任务。费用待确认时仅查状态，完成后通知一次并暂停。失败、取消、过期、用户停止或需要用户处理的阻塞时通知并暂停。不得输出密钥或原始响应。

## 运行条件

本 Skill 使用本地脚本和文件，电脑需要开机、联网，Codex 应用需要在后台运行；不必一直打开当前对话或持续占用当前轮次。关闭应用或关机时不能保证按时检查。独立 CLI/worker 本身不提供 Codex 对话唤醒功能。

依据：[Codex 官方自动任务说明](https://learn.chatgpt.com/docs/automations?surface=app)。

## 两阶段时限补充

每阶段独立记录提交成功 UTC 时间、job_id、一小时提醒是否已发送；重启不重置。超过一小时未收到有效图片提醒一次联系抖音「木纹」主页群，继续每20分钟检查；超过24小时未收到有效图片则标记本地超时失败，暂停调度并通知，不自动重提、不谎称远端已取消。第一阶段交付图A后暂停等待高级设计选择，第二阶段交付图B后结束。两阶段收费分别确认，询问时必须显示第一阶段5次、第二阶段20次额度及实时余额；仍须遵守SKILL.md的实际接口费用边界。
